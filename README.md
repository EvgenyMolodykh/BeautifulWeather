# BeautifulWeather

Приложение для просмотра прогноза погоды.<br> Предоставляет актуальную информацию о погодных условиях: температуру 🌡️, влажность 💧, скорость ветра 🌬️ и тд. Приложение разработано с использованием технологии **WPF** и архитектуры **MVVM** (Model-View-ViewModel).

### Основные функции:
- Отображение текущей погоды.
- Прогноз погоды на несколько дней вперёд.
- Просмотр почасового прогноза.
- Настройка параметров отображения.

### Технологии:
- **Frontend:** WPF (XAML, C#)
- **Архитектура:** MVVM
- **Данные:** API для получения прогноза погоды ([OpenWeatherMap](https://openweathermap.org/api))
